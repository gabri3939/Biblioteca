⚡ COMANDOS SQL RÁPIDOS
════════════════════════════════════════════════════════════

Se precisar corrigir manualmente no phpMyAdmin:

1. Adicionar data_devolucao_prevista:
   ALTER TABLE emprestimos ADD COLUMN data_devolucao_prevista DATE AFTER data_emprestimo;

2. Permitir NULL em endpasta:
   ALTER TABLE livros MODIFY COLUMN endpasta varchar(250) NULL;

3. Verificar estrutura da tabela livros:
   DESCRIBE livros;

4. Verificar estrutura da tabela emprestimos:
   DESCRIBE emprestimos;
